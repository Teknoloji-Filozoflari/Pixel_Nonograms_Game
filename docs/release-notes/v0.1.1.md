# Piksel Nonogram v0.1.1

1.000 çevrim dışı bulmacalı masaüstü oyunu için Linux paketleme güncellemesi.
Mevcut bulmaca kimlikleri, oyun davranışı ve oyuncu ilerlemesi korunur.

## Bu sürümde

- AppImage ve DEB'e ek olarak Fedora RPM, strict Snap ve Nix/NixOS paketi.
- Temiz sistemlerde Qt/X11 açılışı, 1.000 bulmaca, beş dil, SQLite kayıt/yükleme
  ve tam ekran kontrolleri.
- Kaynaktan ve Nix'ten çalıştırmada da `--smoke-test` desteği.
- Python wheel/sdist, temiz GitHub kaynak ZIP'i ve ortak SHA256SUMS.txt.

## Kurulum

```sh
# AppImage — x86_64, glibc 2.36+
chmod +x Pixel_Nonograms-0.1.1-x86_64.AppImage
./Pixel_Nonograms-0.1.1-x86_64.AppImage

# Debian 12/13 amd64
sudo apt install ./pixel-nonograms_0.1.1_amd64.deb

# Fedora 43 x86_64, glibc 2.42+
sudo dnf install ./pixel-nonograms-0.1.1-1.fc43.x86_64.rpm

# Snap — GitHub'dan yerel kurulum
sudo snap install --dangerous ./pixel-nonograms_0.1.1_amd64.snap

# Nix / NixOS — flake desteğiyle
nix run github:Teknoloji-Filozoflari/Pixel_Nonograms_Game/v0.1.1
```

FUSE yoksa AppImage `APPIMAGE_EXTRACT_AND_RUN=1` ile açılabilir.
AppImage sistemin EGL/OpenGL kitaplıklarını kullanır. Debian/Pardus ve
AppImage başlatıcıları varsayılan olarak X11/xcb kullanır; Wayland'da XWayland gerekir.

Snap Store, AUR ve resmî Nixpkgs yayını yapılmadı. Snap verileri sistem
kurulumundan ayrı `~/snap/pixel-nonograms/common` altındadır.
Kayıt taşımadan önce oyun kapalıyken veri klasörünü yedekleyin.

X11 kontrolleri Xvfb üzerinde yapılır. Nix için x86_64 build ve kurulu paket
açılışı doğrulanır; gerçek NixOS, Pardus masaüstü veya ARM64 testi değildir.
Projenin mevcut lisans durumu değiştirilmemiştir; üçüncü taraf lisansları korunur.

Ayrıntılar: [Linux kurulum rehberi](https://github.com/Teknoloji-Filozoflari/Pixel_Nonograms_Game/blob/v0.1.1/README_LINUX.md).
